TB drug-resistance classification

Deterministic, local-in-browser Python interpretation of manually entered drug-susceptibility test (DST) results.

Research / education only — not clinical decision support. A resistance category is not a treatment decision. Missing test results remain unknown. Do not enter patient identifiers. Confirm all findings against laboratory DST, mutation catalogues, and current WHO guidance with an experienced TB clinician. No regimen or dose is generated here.

Technical information

Uses the repository's unmodified Python classifier module at runtime via Pyodide. No clinical advice, inference model, API call, account, or backend is used. The Pyodide runtime itself loads from an external CDN; entered DST values are processed locally in the browser.

Classification uses WHO 2021 MDR/RR-TB, pre-XDR-TB and XDR-TB definitions. Current treatment guidelines: WHO Module 4 (2026). Source code.
